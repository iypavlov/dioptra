# Dioptra

**Dioptra** — десктопное приложение для перевода текста прямо с экрана. Выделите область на экране — приложение распознает текст (OCR) и переведёт его.

## Как это работает

1. Зажмите **Ctrl** (или другую настроенную клавишу)
2. Выделите мышью область с текстом
3. Отпустите клавишу — OCR распознает текст, а переводчик покажет результат

## Возможности

- **OCR** — распознавание текста через `RapidOCR` с предобработкой изображения (увеличение, повышение контраста, sharpen)
- **Два переводчика**:
  - **Google Translate** — бесплатный онлайн-перевод (через `deep-translator`)
  - **Ollama** — локальный перевод через LLM (поддерживаются любые модели, например `llama3.2`)
- **Модальное окно** — результат показывается рядом с курсором, можно скопировать текст мышкой
- **Системный трей** — приложение живёт в трее, оттуда же открываются настройки
- **Авто-скрытие** — сообщения об ошибках исчезают через 2.5 секунды, окно закрывается кликом вне его области

## Установка

### Зависимости

- Python ≥ 3.11
- Ollama (опционально, для локального перевода)

### Из исходников

```bash
# Клонировать репозиторий
git clone https://github.com/iypavlov/dioptra.git
cd dioptra

# Создать виртуальное окружение
python -m venv .venv
.venv\Scripts\activate  # Windows

# Установить
pip install -e .
```

### Сборка исполняемого файла

```bash
pip install -e .[build]
python build.py
```

Готовый `.exe` появится в `dist/Dioptra/`.

## Использование

```bash
dioptra
```

После запуска приложение сворачивается в трей. Зажмите **Ctrl** и выделите область с текстом.

### Настройки

Кликните правой кнопкой по иконке в трее → **Settings**.

- **Translator** — выберите `Ollama` или `Google Translate`
- **Ollama Configuration** — URL сервера, модель, таймаут (кнопка Refresh загружает список доступных моделей)
- **Selection hotkey** — клавиша-модификатор для выделения (например, `ctrl`, `alt+shift`, `ctrl+shift`)

### Отладка

```bash
set DIOPTRA_DEBUG=1  # Windows
dioptra
```

Логи пишутся в `%USERPROFILE%\.screen-translator\dioptra.log`.

## Стек

- **Python ≥ 3.11**
- **PyQt6** — GUI (трей, окна, оверлей)
- **RapidOCR** — распознавание текста
- **mss** — скриншоты выделенной области
- **Pillow** — обработка изображений
- **keyboard / mouse** — глобальные хуки клавиатуры и мыши
- **deep-translator** — Google Translate API
- **Ollama API** — локальный LLM-перевод
- **PyInstaller** — сборка в standalone .exe
